🌐 Endpoints API REST para el Firmware ESP32 (`pluma_wifi.ino`)

El firmware complementario pluma_wifi/pluma_wifi.ino se conecta por Wi-Fi a este servidor usando HTTPClient y sincroniza validaciones, lecturas del HC-SR04 y comandos remotos:

POST /api/esp32/validar-acceso

Valida un UID leído por RC522 o comando Serial ('1'/'0') junto con la distancia del HC-SR04:

{"uid": "83 CF 7A 28", "distancia_cm": 42.0, "origen": "RFID_RC522"}
POST /api/esp32/telemetria

Reporta en tiempo real la distancia del sensor ultrasónico HC-SR04 y recibe comandos de apertura remota:

{"distancia_cm": 6.5, "pluma_estado": "CERRADA"}
GET /api/esp32/uids-autorizados

Descarga la lista de UIDs activos desde SQLite para respaldo offline en la memoria del ESP32.
